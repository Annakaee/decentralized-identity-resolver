# decentralized-identity-resolver

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)

A universal Web3 utility library to resolve DIDs, ENS domains, and Stellar federated addresses into a unified, human-readable user profile.

## Features
- Fully typed and robust implementation
- Highly customizable and modular
- Built for the modern Web3 ecosystem
